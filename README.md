Student Dropout Analysis

A Python-based Exploratory Data Analysis (EDA) project analyzing student academic and demographic data to understand patterns across **Graduate, Dropout, and Enrolled** outcomes.

Dataset
* 4,424 student records
* 37 variables
* No missing values reported
* Target: `Graduate`, `Dropout`, `Enrolled`

Tools
* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab / Jupyter Notebook

Analysis

The project includes:

* Dataset inspection
* Data quality checks
* Target distribution analysis
* Exploratory analysis
* Data visualization

Files

`Week_4_Task.ipynb` — Complete analysis notebook.
